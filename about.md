# Temu Frame Perfect Counter

Temu Frame Perfect Counter is an independent Geode mod prototype for Geometry Dash. It records gameplay input events, shows colored markers at recorded press positions, displays simple interval counters, and exports CSV data for further analysis.

This release is an input timeline recorder, not a complete frame-window scanner. Interval categories do not establish a true frame-perfect window. Bot/replay compatibility varies depending on how each tool injects inputs and must be verified individually.

The project is not affiliated with or endorsed by FB Frame Counter or its developers.
