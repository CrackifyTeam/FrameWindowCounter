# Contributing

Thanks for helping improve Temu Frame Perfect Counter.

## Bug reports

Include:
- Geometry Dash version
- Geode version
- Android architecture (Android32 or Android64)
- Steps to reproduce
- Relevant GitHub Actions build log, if the issue is a build failure

## Changes

Keep changes focused and describe what was tested. Do not claim true frame-window detection unless it has been validated with controlled replay/input-shift tests.
